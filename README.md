# Nyxa Network

The public website for **Nyxa Network** ([nyxa.cash](https://nyxa.cash)), a private payment pool named for Nyx. This repository is the site only. It is not the protocol, and it does not contain contracts.

Nyxa is in development. The tagline is “Pay in the dark. Leave no trace.” That is the aim of the design, not a claim about a system you can use today.

## Status

- Privacy pool contracts are **not deployed**.
- The app at `/app/` can connect an EIP-1193 wallet (MetaMask, Rabby, OKX Wallet, and other injected wallets) and read the **real** account, network, and native balance. Veil, Whisper, Eclipse, and Crossing forms validate input. Their buttons stay disabled and read **Launching soon**. The page does not submit a transaction.
- **$NYXA** is deployed on Robinhood Chain (chain id 4663). The contract name is NYXA NETWORK and the symbol is NYXA. Contract address: `0xfabf7473d2847e7a8c650851b64737d15505cf0c`. Explorer: [robinhoodchain.blockscout.com](https://robinhoodchain.blockscout.com/address/0xfabf7473d2847e7a8c650851b64737d15505cf0c). No code for this address was found on Base, Arbitrum, or BNB Chain.
- No audit is claimed.
- The official X account is [@nyxanetwork](https://x.com/nyxanetwork). It is linked in the footer, next to the GitHub repository [github.com/nyxaagent-max/nyxa](https://github.com/nyxaagent-max/nyxa).

The site does not show invented balances, totals, user counts, testimonials, partners, or transactions. Diagrams are labelled as illustrations of how the flow is planned to work.

## Product names

| Name | Plan |
| --- | --- |
| Veil | Deposit ETH, USDC, or USDG as an encrypted note |
| Whisper | Private send; a relayer pays gas |
| Eclipse | Private swap inside the pool |
| Crossing | Private move across Robinhood Chain, Base, Arbitrum, and BNB Chain, with Solana as a destination |
| Dawn | Recovery from the wallet that created a note |
| Builders | A future CLI and API for AI agents |

## Pages

The header is the logo, a Protocol menu, and Launch App. Protocol lists Veil, Whisper, Eclipse, Crossing, Dawn, Network, Roadmap, Builders, Learn, and $NYXA. Learn links onward to the path, the craft, and questions. `/app/` connects a wallet.

The home page and the app include a live terminal labelled “Live network feed — public chain data”. It reads block number, gas, and recent transaction hashes from the public RPCs for Robinhood Chain, Base, Arbitrum, and BNB Chain. Those figures are chain data, not Nyxa payments. If a request fails, the line says `reconnecting…`.

The roadmap is four phases with no dates: website (current), testnet pools and relayer, audit, mainnet.

The craft page describes the planned architecture only: proofs built in the browser, a relayer, Merkle-tree notes, and a non-custodial design. It is not a specification freeze and not an audit.

## Local preview

Root-relative links need a local server.

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

Page shells are generated by `scripts/render.mjs` so the header and footer stay consistent. Edit that script, then run:

```bash
node scripts/render.mjs
```

The committed HTML, CSS, and JavaScript are what GitHub Pages serves. A build step is not required to view or deploy the site.

## Deployment

`CNAME` contains `nyxa.cash`. The workflow `.github/workflows/pages.yml` deploys the site to GitHub Pages when `main` changes.

In the repository settings, set **Pages → Source** to **GitHub Actions**.
