Planned architecture

The plan, written plainly.

An overview of the architecture Nyxa intends to build. Not a specification freeze, not an audit, and not a description of deployed code. There is no deployed code.

Four planned parts

Planned

Builds the proof from the note. The secret is not meant to leave the device.

Arrival

The recipient is paid. The link back to a specific deposit is what the design withholds.

Non-custodial notes

The design is non-custodial: Nyxa should never take custody of a note’s spend secret. Keys stay with the holder. That cannot be verified against deployed contracts, because none are deployed. Dawn, the recovery path, is still a signature by the holder’s own wallet — not a backup kept by us.

Proofs in the browser

The plan is to generate the zero-knowledge proof in the browser, so the raw note does not have to be sent to a server for someone else to prove. Which proving system, and which circuit, is not decided. This page will not pretend that it is.

Merkle tree of notes

Deposits are planned as commitments inserted into a Merkle tree. A later spend would prove knowledge of a leaf without revealing which leaf. The tree has no root today, because the contract that would hold it does not exist.

The relayer

A relayer is planned to submit the withdrawal and pay the network fee. That is how the payer’s own wallet stays off the transaction. Relayer selection — open, allowlisted, or operated — and the fee are not published yet. A relayer necessarily sees the transaction it submits.

What would stay public

  • That a deposit of a given asset and size entered a pool.
  • That a payment of a given asset and size arrived.
  • The relayer’s address as the transaction sender.
  • The recipient address.

What is deliberately undecided

  • The proving system.
  • The fee schedule.
  • Who may run a relayer.
  • The exact note format.
  • Contract addresses. There are none to publish.
Not an audit. Nothing on this page is a security review. No third party has been claimed as an auditor of Nyxa.
