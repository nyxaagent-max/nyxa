Nyxa Network / Dawn

In development

Morning, if you can still sign.

Dawn is recovery. If you can still sign with the wallet that created a note, Nyxa is being designed so that signature is enough to reconstruct access. Nyxa does not keep the secret.

There is no support desk that can unlock a note for you, because the plan is that Nyxa never holds it. If the design works as intended, losing both the wallet and the secret means nobody — including Nyxa — can recover the note.

Treat that as the point of a non-custodial design, and as a reason it has to be reviewed before anyone relies on it. It cannot be reviewed against deployed code today. There is no deployed code, and no audit is claimed.

  1. 01

    Same wallet

    Dawn is for the key that created the note, not for a stranger who knows an address.

  2. 02

    A signature

    The planned recovery uses a signature from that wallet. The exact message format is not final.

  3. 03

    No custody

    Nyxa storing a backup of your secret would break the design. It is not part of the plan.

Not a rescue service. Do not send a seed phrase to anyone who claims they can restore a Nyxa note. The product is not live, and the plan is that we cannot restore it.
