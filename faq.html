Nyxa Network / FAQ

Plain answers

Questions, without theatre.

Short answers about what exists today. If a question is about a user count or a total locked, the answer is that we do not publish figures we do not have.

Is Nyxa Network live?

No. Nyxa is in development. The contracts are not deployed. The website describes the product being built and lets a wallet connect so you can see your own address and native balance. It cannot veil, whisper, swap, or cross.

Can I deposit or send today?

No. In the app, the action button is disabled and labelled “Launching soon”. Filling in a form does not create a transaction. If a submit event fires anyway, the page refuses it and sends nothing.

Why connect a wallet if nothing can be sent?

So the app can show the real account, the real network, and the real native balance from that wallet. It is a window onto your wallet, not a till. Nyxa will not ask for a seed phrase.

Has Nyxa been audited?

No audit is claimed. There is no deployed system to audit, and this site does not name an auditor, a report, or a date.

What is the $NYXA contract address?

There isn’t one. The token is not launched. The contract address will be announced only on official channels, and this website will be updated when that happens. It is blank on purpose.

Which assets are planned?

ETH, USDC, and USDG. Token balances are not shown in the app, because Nyxa has no contracts to read and this page does not look up someone else’s token addresses. The balance you see is the network’s native gas token, from your wallet.

Which chains are planned?

Robinhood Chain, Base, Arbitrum, and BNB Chain as pool networks. Solana as a destination only. Chain ids and public endpoints are listed on the Chains page. None of them host a Nyxa contract.

Does Nyxa hold funds?

The design is non-custodial: the spend secret of a note stays with the holder. Nyxa is not holding funds today because it cannot accept them. There is no deposit address.

What would a relayer see?

The withdrawal it is asked to submit, including the destination, because it has to broadcast that transaction. The pool is designed so other observers cannot match that withdrawal to a specific deposit. That matching resistance is a goal, not a measured result.

Does “leave no trace” mean nobody can see anything?

No. It is the aim of the design: remove the public link between a deposit and a later payment. Recipients see arrivals. Relayers see what they send. Amounts and timing still exist. A full privacy analysis waits until the design is frozen and actually reviewed.

Is there an official social account?

Not yet. There is no official X account. The only profile linked from this site is the GitHub repository in the footer.

Someone sent me a contract address and called it $NYXA. Is it real?

No. Nyxa Network has not launched the token. An address in a reply, an ad, or a direct message is not an announcement. Do not buy it and do not send funds to it.

What is Dawn for?

Recovery of a note from a signature by the wallet that created it. It is not a help desk, and it is not a way for Nyxa to reconstruct a secret we never stored. The exact signature format is not final.

Is the animation a live payment?

No. Anywhere you see the sequence Veil → Prove → Relay → Arrive, it is labelled as how it works. It is an illustration of the plan.
