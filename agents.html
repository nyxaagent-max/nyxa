Nyxa Network / Agents

Planned

A quiet interface for agents.

Nyxa for agents is a planned command-line tool and HTTP API, so software can veil, whisper, swap, and cross under rules a person sets. Nothing is installable today.

There is no package name to install, no base URL to call, and no API key to request. Publishing a command here that looks live would send people to a tool that does not exist.

What the interface is for

  • Veil, whisper, eclipse, and crossing, each as an explicit action.
  • A policy the operator controls: which assets, which chains, which size.
  • The same constraint as the app: no action before contracts exist.

Sketch, not a published interface

The lines below show the shape of a future command. They do not run. There is no binary by this name.

# Sketch only. These commands are not published and will not run.
nyxa veil --asset USDC --amount AMOUNT
nyxa whisper --to ADDRESS --asset USDC --amount AMOUNT
